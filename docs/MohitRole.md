# Mohit Role: Team Lead, Full-Stack Integration, Backend & AI/ML

## Primary Responsibility
Own overall project architecture, coordination, integration, and technical delivery. Also contribute directly to backend development and AI/ML implementation.

## 1. Team Leadership
- Define the project structure and technical implementation plan.
- Break the problem statement into small, achievable tasks.
- Assign tasks to Rohit and Gaurav based on their responsibilities.
- Track progress, blockers, and deadlines in `TASK_BOARD.md`.
- Review technical decisions and coordinate changes affecting multiple modules.
- Ensure the team focuses on a working MVP before adding optional features.

## 2. Backend Engineering
- Design and implement backend routes, services, and data models.
- Define API contracts with the frontend and AI/ML owners.
- Implement input validation, authentication if required, and error handling.
- Integrate the database and external services where needed.
- Write and run backend tests.
- Maintain `.env.example` and document backend setup.
- Coordinate backend changes with Rohit if they affect his frontend or AI/ML integration work.

## 3. AI/ML Engineering
- Help select a feasible model or prediction approach for the problem.
- Implement core inference logic when needed.
- Define interfaces between AI/ML services and the backend.
- Validate outputs, handle model failures, and measure relevant performance.
- Help integrate the model into the working application.

## 4. Project Integration
- Maintain the overall architecture and shared interfaces.
- Connect frontend, backend, database, and AI/ML components.
- Resolve integration issues and coordinate merge conflicts.
- Test complete user journeys from input to final result.
- Ensure the application can be started reliably using documented commands.

## 5. Git and Code Review
- Keep the shared `main` branch usable.
- Coordinate direct pushes and ensure teammates pull before pushing.
- Review high-impact changes and inspect integration risks.
- Never overwrite another member's work or use force-push on shared `main`.

## 6. Deliverables
- Working project structure and architecture documentation.
- Backend endpoints and agreed API contracts.
- Integrated MVP.
- Updated task board and technical decisions.
- Successful end-to-end demo with documented limitations.

## Working Rule
Prioritize integration and delivery over taking every task personally. Delegate independent implementation work and intervene directly when a shared interface or integration problem requires it.
