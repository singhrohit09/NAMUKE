# Rohit Role: Frontend Engineer & AI/ML Engineer

## Primary Responsibility
Own the user-facing application and contribute to the AI/ML pipeline. Build a frontend that communicates reliably with the backend and presents AI-generated results clearly.

## 1. Frontend Engineering
- Build the application layout, pages, and reusable UI components.
- Implement forms, input validation, loading states, error messages, and success states.
- Integrate backend APIs using the agreed API contracts.
- Display predictions, analysis, results, and status information clearly.
- Make the interface responsive and usable on different screen sizes.
- Add charts, maps, tables, or visualizations only when they help solve the problem.
- Test the main user journey and handle failed API requests.

## 2. AI/ML Engineering
- Assist Gaurav with data preprocessing and model integration.
- Implement supporting inference or data-transformation logic when assigned.
- Help validate model inputs and outputs.
- Test edge cases and identify incorrect or inconsistent results.
- Coordinate model interface changes with Gaurav and Mohit.
- Avoid duplicating an existing model pipeline without a clear reason.

## 3. Frontend and AI Integration
- Work with Mohit to define how AI results appear in the interface.
- Agree on request and response formats before implementation.
- Keep mock data clearly separated from real API responses.
- Ensure the UI remains usable when the model or backend is unavailable.

## 4. Testing and Quality
- Test forms, navigation, API calls, and error states.
- Check responsive layouts and accessibility basics.
- Report bugs with reproduction steps.
- Do not claim functionality works until it has been tested.

## 5. Git and Collaboration
- Primarily own the frontend directory and assigned UI files.
- Coordinate before modifying shared configuration or backend files.
- Pull the latest `main` before pushing.
- Commit small, meaningful changes and resolve conflicts without discarding valid work.

## 6. Deliverables
- Functional, responsive frontend.
- Integrated API-driven user journeys.
- Clear visual presentation of AI/ML outputs.
- Frontend testing results and setup documentation.

## Working Rule
Build against agreed API contracts. Use mock responses only to unblock development, then replace them with verified backend integration before the final demo.
